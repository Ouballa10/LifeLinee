Introduction

C'est quoi LifeLine ?

Une application web mobile-first qui permet à tout utilisateur d'enregistrer ses informations médicales et de générer un QR code personnel. En cas d'urgence, ce code est scanné pour afficher une fiche médicale instantanément — sans application, sans compte.

🔴 Urgence médicale 📱 PWA Mobile-first
👤

Utilisateur

Crée un compte, complète son profil médical, génère et partage son QR code.

🚑

Secouriste

Scanne le QR code et accède à la fiche médicale publique — sans avoir de compte.

🔒

Sécurité

Données privées protégées par Firebase Auth + Supabase RLS. Seules les infos nécessaires sont exposées.

04 / 09
Problématique

Le problème réel

« Comment permettre un accès rapide, simple et sécurisé aux informations médicales essentielles d'une personne inconsciente ou incapable de communiquer lors d'une urgence ? »

⏱️
Chaque seconde compte lors d'une urgence médicale
🚫
Les infos médicales ne sont pas toujours disponibles sur place
📲
Un QR code suffit — aucune installation requise pour le secouriste

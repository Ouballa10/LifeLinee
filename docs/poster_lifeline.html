LifeLine
Application Web Médicale d'Urgence basée sur QR Code
Réalisé par : Abdelmounaim Ouballa  |  Encadré par : Pr. LAFHAM Mohamed
⚠️
Problématique

Lors d'une urgence médicale, une personne peut être inconsciente ou incapable de communiquer ses informations médicales critiques.

Comment permettre un accès rapide, simple et sécurisé aux informations médicales essentielles d'une personne en cas d'urgence ?

💡
Solution Proposée

LifeLine est une application web mobile-first qui permet à l'utilisateur de :

  • Enregistrer ses informations médicales essentielles
  • Générer un QR code personnel unique
  • Rendre ces données accessibles aux secouristes via un simple scan
✨
Fonctionnalités Clés
  • Authentification sécurisée (Email + Google)
  • Profil médical complet et modifiable
  • Génération de QR code stable et unique
  • Scanner QR (caméra + import image)
  • Fiche d'urgence publique accessible sans compte
  • Appel direct du contact d'urgence
  • Mode hors ligne (PWA)
  • Interface responsive mobile-first

Base de Données

Tables principales :

  • user_profiles — Données personnelles
  • medical_profiles — Données médicales + QR token
  • emergency_logs — Historique des accès

Vue publique :

  • public_emergency_profiles — Données limitées pour les secouristes

Résultats
  • Application fonctionnelle et déployée
  • Accès à la fiche médicale en < 3 secondes
  • Compatible tous smartphones modernes

Perspectives
  • Notifications aux contacts d'urgence
  • Géolocalisation lors du scan

Conclusion

LifeLine répond à un besoin réel en rendant les informations médicales essentielles accessibles rapidement via un QR code unique.

L'architecture moderne (React, Express, Supabase, Firebase) assure performance, sécurité et maintenabilité.
